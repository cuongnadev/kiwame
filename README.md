## 🎯 Introduction

**Kiwame** is a modern video-sharing platform similar to YouTube, built with **Next.js** and **Supabase**, featuring:

- Video upload, playback, comments, and user channels  
- **Live streaming** capabilities  
- **AI-powered recommendation system** that personalizes video suggestions  
- Secure authentication and storage powered by **Supabase**

This project is part of the **Undergraduate Capstone Project (Course: Software Engineering)**  
at **Vietnam–Korea University of Information and Communication Technology (VKU)**.

## ⚙️ Installation Guide – Development Mode

First, start the development environment:

```bash
# Clone the repository
git clone git@github.com:cuongnadev/kiwame.git

# Navigate into the project folder
cd kiwame

# Install dependencies
pnpm i

# Copy and configure your environment file
cp .env.example .env.development

# Run the development server
pnpm run dev
```
